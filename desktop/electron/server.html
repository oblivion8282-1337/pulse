Selbst-gehosteter Pulse-Server auf diesem Gerät.
Initialisiere …
Du bist eingeloggt. Die Einrichtung findet deine freigegebene Instanz und verbindet dieses Gerät automatisch.
Automatische Einrichtung fehlgeschlagen — minte das Token manuell in deinem Konto und füge es ein.

Kopiert
So laden deine Freunde ein: Öffne den Pulse-Client, erstelle eine Community auf deinem Server und erzeuge dort einen Einladungslink (Leute einladen → Oder Link teilen).
Ob Freunde wirklich durchkommen, siehst du beim ersten Beitritt.
Dauerbetrieb einrichten
  1. Den Schalter oben aktivieren — die Server-App startet dann mit deiner Anmeldung.
  2. Automatische Anmeldung deines Benutzerkontos in den Systemeinstellungen aktivieren, damit das Gerät ohne Zutun hochkommt.
  3. Im BIOS/UEFI (bzw. bei Macs in den Energieeinstellungen) „Nach Stromausfall automatisch einschalten" aktivieren.

Deine Daten

Alle Nachrichten und Dateien deines Servers liegen auf diesem Gerät — nichts davon in der Cloud.

Server übernehmen?

Für dieses Konto läuft bereits ein eingerichteter Server. Übernehmen? Der bisherige Server verliert dauerhaft den Zugang.

Backup importieren?

Ersetzt alle aktuellen Serverdaten auf diesem Gerät durch den Inhalt der Backup-Datei (Nachrichten, Dateien — unwiderruflich). Der Server wird dafür kurz gestoppt.

Server aufgeben?

Dein Server wird dauerhaft gelöscht. Mitglieder verlieren den Zugang und der Server verschwindet aus ihren Listen.
