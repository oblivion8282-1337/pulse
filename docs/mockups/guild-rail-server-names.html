Guild-Rail: voller Self-Host-Servername

Vier Varianten, wie die linke Spalte lange Hostnamen wie pulse.unicutmedia.com zeigen kann, ohne das Icon-Rail-Design zu verlieren. Zum Vergleich links jeweils der Ist-Zustand („PU ·“). Beispieldaten: Pulse-Cloud + zwei Self-Hosts (pulse.unicutmedia.com, chat.familie-mueller.de).

BWrap-Label — Rail bleibt schmal

Der Hostname wird in Mini-Schrift über bis zu 3 Zeilen umbrochen statt auf Initialen gekürzt. Breite (64 px) und alles andere bleiben unverändert.

EAnzeigename statt Hostname

Jeder Server bekommt einen kurzen, menschlichen Anzeigenamen („Unicut Media“ statt pulse.unicutmedia.com) — vom Server-Betreiber gesetzt, lokal per Rechtsklick überschreibbar.
